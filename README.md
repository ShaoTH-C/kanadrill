# kanadrill

练日语假名读音的网页。给假名写罗马字，或者给罗马字手写假名、自动核对。

在线用：https://shaoth-c.github.io/kanadrill/

## 能干什么

- 认读：屏幕出假名（单词或单个假名），输入罗马字，自动批改。接受 Hepburn / 训令式 / 长音符号 / nn 这些写法，答错时逐个假名标注读音，告诉你错在哪一个。
- 听写：屏幕出罗马字和词义，你在格子里一格一个手写假名，点"核对"自动判。判错了告诉你哪一格不对、像哪个假名，并把标准写法叠在你写的字上。也可以在纸上写，点"直接看答案"自己判。两种都能改判。
- 五十音图：清音、浊音、半浊音、拗音、外来语专用音，平假名 / 片假名 / 对照三种显示。有日语语音包的设备可以点格子发音。每一区都能勾几行直接出题。
- 错题本按题型分开记，连对两次自动移出；没做过的词优先出。
- 全部存在浏览器 localStorage 里，没有后端。

## 题库

`data.js` 里 2346 个词（平假名 1415，片假名 931），全部是纯假名写法，附中文释义。
难度分入门 / 进阶 / 挑战三档，按拍数、浊音、拗音、促音、长音自动算，不是手标的。

罗马字由 `check.js` 从假名推出来，所以词表里只需要维护假名和释义。加词后跑一次 `npm test`，
会检查每个词能被批改器接受、没有重复、难度标签对得上。

## 手写核对

`recog.js` 把笔迹按方向分到一张 10x10 的网格上（4 个方向通道，高斯模糊），跟 `strokes.js` 里的
假名骨架比余弦距离，取最近的。浊点和半浊点分不开的时候换 16x16 的细网格再比一次差异加权距离。
笔顺、笔画数、连笔、拆笔都不影响判定，写歪写扁靠 27 个小仿射预扭吸收。判定前按抖动量做自适应
平滑，不然鼠标手抖会把方向通道填满噪声。

前五行是 `npm test` 里的断言，157 个假名 × 7 档合成形变（抖动、旋转、拉扁、剪切、弹性变形、
连笔、拆笔、乱序）：

| | |
|---|---|
| 写对了被收下 | 98.7% |
| 写成同体系另一个假名 | 100% 拒 |
| 该写片假名却写了平假名（反之亦然） | 100% 拒 |
| 清音浊音写反 | 100% 拒 |
| 乱涂 | 100% 拒 |
| 单字耗时 | 9 ms |

下面两行是开发时另外量的，样本没进仓库所以 `npm test` 跑不到：把八种日文字体的字形细化成骨架
当作"另一种笔迹"，收下 97.9%（1256 个样本）；故意少写一笔，只有 63% 被判错。

判不了的：笔顺（方向栅格不看先后）、小写假名的大小（っ 和 つ 判为同一个）、
长音符 ー（一道大致水平的横就算对）。

## 本地跑

没有构建，直接打开 `index.html` 就行。测试需要 node 20+：

```
npm test
```

## 已知限制

- 发音靠系统的 Web Speech 日语语音，Windows 要在语言设置里装日语语音包，没有就不显示发音按钮。
- 假名字体走 Google Fonts，拉不到时退回系统日文字体。
- 手写核对只判字形，不判笔顺，也不判小写假名写得够不够小。
